# Мини-приложение MAX

Первый экран показывает «Привет, мир!» сразу при открытии. Подключён официальный
MAX Bridge; текст отображается и в обычном браузере, даже если Bridge недоступен.
Бэкенд и бот пока остаются заготовками.

## Локальный запуск

Нужен Node.js 22 или новее. Из корня проекта:

```powershell
node webapp/server.mjs
```

Откройте http://127.0.0.1:3000. Остановка — Ctrl+C. После изменения HTML
перезапустите сервер и обновите страницу. Установка npm-зависимостей не нужна.
Если npm установлен, в папке `webapp` можно использовать `npm run dev`
или `npm start`. В режиме dev после изменения HTML также нужен перезапуск.
Переменные окружения `HOST` и `PORT` меняют адрес и порт сервера.

## Открытие в MAX

1. Разместите `webapp/index.html` на статическом хостинге с публичным HTTPS-адресом
   либо направьте HTTPS-туннель на локальный порт 3000.
2. На платформе MAX для партнёров откройте «Чат-боты», выберите своего бота,
   затем ⋮ → «Настройки».
3. Укажите публичный HTTPS-адрес мини-приложения, выберите кнопку открытия
   и сохраните настройки.
4. Откройте мини-приложение через бота: на экране должно появиться «Привет, мир!».

Локальный адрес предназначен только для проверки на компьютере.
Для этого экрана не нужны токен бота, API-запросы или скачанные сертификаты.
Сертификаты доверия для соединения с API не заменяют HTTPS-сертификат хостинга.
Не размещайте приватные ключи и токены среди публичных файлов приложения.

Документация: [подключение мини-приложения](https://dev.max.ru/help/miniapps),
[MAX Bridge](https://dev.max.ru/docs/webapps/bridge).
